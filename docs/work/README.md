# docs/work: working notes of finished lanes

Nothing in this folder is a live design or reference for the B70 fork. Everything here is the record of upstream's
macOS-first "Phase A" rebuild of Strata (the notes name a Mac with an Apple M4, a macOS app, a Tauri desktop shell and the
DeepSeek Harness). The desktop app, the Metal engine and the packages it built were removed from this fork (see
[../FORK.md](../FORK.md)). The files are kept as history only. Paths, commands and revisions inside them are as they were
written and are not updated.

The live B70 notes are [../B70.md](../B70.md), [../Q36.md](../Q36.md), [../B70_LIB.md](../B70_LIB.md) and
[../INTEL.md](../INTEL.md).
